Extract the files from aspDemo4.zip.

Create a new ASP.Net Core Web Application Project within your ASP folder.  Call the project, Demo4.

Add ProductDataController.cs to the Controllers folder.

Add Category.cs, PaginatedList.cs, Product.cs, SubCategory.cs, TaraStoreContext.cs to the Models folder.

Replace Index.cshtml in the Views/Home folder.

Create a new Views Folder, ProductData.

Add FilterDemo.cshtml, ListView.cshtml, PaginationDemo.cshtml, SortDemo.cshtml, SortFilterPageDemo.cshtml, TableView.cshtml to the Views/ProductData folder.

Replace _Layout.cshtml in the Views/Shared folder.

Add _ProductListView.cshtml to the Views/Shared folder.

Replace appsettings.json and Startup.cs in the project (i.e., Demo4) folder.
