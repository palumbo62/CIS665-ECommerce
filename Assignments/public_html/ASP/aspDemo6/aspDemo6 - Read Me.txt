Extract the files from aspDemo6.zip.

Create a new ASP.Net Core Web Application Project within your ASP folder.  Call the project, Demo6.

Add AccountController.cs, RestrictController to the Controllers folder.

Replace HomeController.cs in the Controllers folder

Add Category.cs, LoginInfo.cs, LoginInput.cs, Product.cs, SubCategory.cs, TaraStoreContext.cs, TblOrder.cs, TblOrderDetail.cs to the Models folder.

Add Open.cshtml to the Views/Home folder

Replace Index.cshtml in the Views/Home folder.

Create a new Views Folder, Account.

Add Login.cshtml, SignUp.cshtml to the Views/Account folder.

Create a new Views Folder, Restrict.

Add MyOrders.cshtml, AllOrders.cshtml to the Views/Restrict folder.

Replace _Layout.cshtml in the Views/Shared folder.

Replace appsettings.json and Startup.cs in the project (i.e., Demo6) folder.
